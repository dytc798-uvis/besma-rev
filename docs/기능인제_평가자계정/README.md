# 기능인제 평가자(소장·팀장) 아이디/비밀번호

## 데이터 출처

| 파일 | 용도 |
|------|------|
| `docs/월별현장별집계_*.xls` | 현장명·별칭·대표(소장 보조) |
| `docs/출역일보_*.xls` | 팀장(대표)·당일 출역 |
| `docs/sample/site_import/raw/daily_workers_raw*` | 일용직 명부 — 현장별 직종=1 소장·주민번호 |
| `docs/sample/site_import/raw/사원리스트_*.xls` | ERP 사원리스트 — **이름→주민번호 보조** (최신 우선) |

## 평가·계정 규칙

- **평가자:** 소장, 팀장
- **소장:** 직영 + 팀장 평가
- **팀장:** 본인 제외 팀원 평가
- **10명 이하 현장:** 소장만 (팀장 ID 없음)
- **팀장 없음 / 대표명이 사람 이름 아님:** 소장이 전원 평가, 팀장 ID 없음
- **팀장이 당일 출역하지 않음:** 팀장 ID 없음, 해당 팀원은 소장이 평가 (비고에 표시)
- **아이디:** `{별칭}-{이름}` (예: `대우청라-박명식`)
- **비밀번호:** 출역일보 주민번호 앞 6자리 (팀장은 본인 출역 행 기준)

## 생성

```bash
cd backend
PYTHONPATH=. python scripts/generate_functional_eval_evaluator_account_sheets.py
```

출력:
- `기능인제_평가자계정_관리용_YYYYMMDD.xlsx`
- `기능인제_평가자계정_배포용_YYYYMMDD.xlsx`
