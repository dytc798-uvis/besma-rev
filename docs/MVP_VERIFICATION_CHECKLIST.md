## MVP 종료 판정 기준 (제안)

### P0 — 없으면 종료 불가

- [ ] 로그인·로그아웃·역할별 홈 (Phase 1 전체)
- [ ] SITE: 문서 업로드 → HQ 승인/반려 → 재제출 (2.14 + 3.4~3.7)
- [ ] HQ: 문서 취합·회차 히스토리·파일 다운로드 (2.9~2.15)
- [ ] C18 실데이터: 복원 파일 열림 + 히스토리 상태 정상

### P1 — 권장 (현장/본사 일상)

- [ ] 일일안전회의 모바일 허브 (3.9~3.12)
- [ ] 본사-현장 소통 양방향 (2.19~2.21 + SITE 소통)
- [ ] 근로자의견·부적합 대장
- [ ] 공지·방침·안전교육 캘린더

### P2 — 시즌/역할 한정

- [ ] 기능인제 · 신규현장 배포 · 사고관리

### 종료 가능 신호

- P0 **전부 ✅**
- P1 **80% 이상 ✅**, 나머지 ⚠️(문서화된 한계)
- Phase 5 항목 **이해·수용** 또는 **숨김 처리 완료**
