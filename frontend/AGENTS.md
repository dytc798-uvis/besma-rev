# BESMA 화면 빌드

- 빌드는 `node build-preview.mjs`를 사용한다. Vite 기본 빌드로 바꾸지 않는다.
- 공개본의 배포 ID·Git 커밋과 파일 해시를 확인한 뒤 변경분을 반영한다. 다른 세션의 최신 배포를 보존한다.
- `monthly-source-names-release/baseline.json`은 확인한 공개 파일의 기준이다. 불일치가 나면 건너뛰지 않고 현재 공개본과 대조한다.
- 빌드 확인 기록은 `.vercel/output` 밖에 둔다. 인증정보·업무 원문·내부 보고서를 공개 파일에 포함하지 않는다.
- 로그인 유지·역할·기존 평가·서명·업로드 이력과 수집 예약을 보존한다. 운영 배포는 최신 소통폴더의 점유와 배포 상태를 확인한다.
